## 🚀 快速开始

```bash
# 克隆项目
git clone https://github.com/dirjaker/hermes-skill-guide.git
cd hermes-skill-guide

# 创建虚拟环境
conda create -n hermes-skill-guide python=3.12 -y
conda activate hermes-skill-guide

# 安装依赖
pip install -r requirements.txt

# 运行项目
python main.py
```
